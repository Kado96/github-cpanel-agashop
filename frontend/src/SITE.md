# AgaShop Site Vision & Roadmap

Ce document sert de mémoire à long terme pour l'évolution visuelle et fonctionnelle d'AgaShop.

## 1. Core Identity
- **Project Name:** AgaShop
- **Mission:** Fournir une plateforme de gestion de boutique ultra-professionnelle, simple et puissante.
- **Target Audience:** Commerçants, Gérants de boutique, Administrateurs.
- **Voice:** Expert, Rassurant, Clair.

## 2. Visual Language
- **The "Vibe":**
    - *Primary:* Professional
    - *Secondary:* Clean
    - *Tertiary:* High-Tech

## 3. Architecture & File Structure
- **Framework:** Ionic Vue
- **Style:** SCSS / Global Variables
- **Strategy:** Composants réutilisables, styles centralisés dans `variables.css`.

## 4. Live Sitemap (Current State)
- [x] `ShopHome.vue` - Tableau de bord principal.
- [x] `ShopStats.vue` - Analyses et graphiques (Premium).
- [x] `Expenses.vue` - Gestion des dépenses.
- [x] `Products.vue` - Inventaire et ajout de produits.

## 5. The Roadmap (Design Overhaul)
### High Priority
- [ ] Migration vers `Inter` & `Outfit`.
- [ ] Refonte du `variables.css` (Palette 2026).
- [ ] Modernisation du Header (Glassmorphism).

### Medium Priority
- [ ] Refonte des cards sur le Dashboard.
- [ ] Amélioration de l'ergonomie des formulaires.

## 6. Rules of Engagement
1. Toujours vérifier la lisibilité sur les petits écrans.
2. Maintenir une palette de couleurs sobre (évitement des couleurs criardes).
3. Utiliser les icônes Ionicons de manière équilibrée.
